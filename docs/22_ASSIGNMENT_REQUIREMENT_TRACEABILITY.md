## 2. Evidence Recommended for Assignment Submission

When preparing project submission materials or reports, capture the following verified evidence:

1. **Maven Reactor Build Output**:
   - Command: `mvn clean package`
   - Screenshot/Log: Shows all 4 modules building successfully with `BUILD SUCCESS`.
2. **Arquillian Integration Test Results**:
   - Command: `mvn -Parquillian-payara -pl globaltrade-ejb verify`
   - Screenshot/Log: Shows `Tests run: 16, Failures: 0, Errors: 0, Skipped: 0` and `BUILD SUCCESS`.
3. **Payara Server Admin Console**:
   - `http://localhost:4848` showing `GlobalTradeCustomRealm` under Security Realms and `jdbc/GlobalTradeDS` under JDBC Resources.
   - Applications screen showing `globaltrade` EAR deployed and enabled.
4. **Database Verification**:
   - MySQL Workbench or CLI showing tables in `globaltrade_db`, particularly `audit_logs`, `app_users`, `user_roles`, and `vendor_user_access`.
5. **Postman / cURL API Responses**:
   - Health check: `GET /globaltrade/api/health/database` (200 OK).
   - Unauthenticated challenge: `GET /globaltrade/api/security/whoami` (401 Unauthorized).
   - Fine-grained allowed: `GET /globaltrade/api/business-security/vendor/1` with `gt_vendor` (200 OK).
   - Fine-grained denied: `GET /globaltrade/api/business-security/vendor/2` with `gt_vendor` (403 Forbidden).
   - Rollback verification: `POST /globaltrade/api/transactions/dispatch/fail` with `gt_admin` (200 OK with `rollbackVerified: true`).
